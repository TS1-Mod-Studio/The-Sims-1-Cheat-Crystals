Sept objets animés pour modifier les fonds du foyer, les besoins, les compétences, les relations, la carrière, la célébrité et les ressources magiques. Vous pouvez installer le lot complet ou choisir vos cristaux. Chacun coûte §1 dans le mode Achat, sous Divers → Tout (∞). Placez-le sur le terrain, sélectionnez un Sim et cliquez sur le cristal pour ouvrir son menu.

## Téléchargement

**[Télécharger les cristaux de triche – GitHub Releases](../../releases/latest)**

Téléchargez l’archive ZIP dans la section Assets de la dernière version. Elle contient les sept fichiers IFF et des instructions en 17 langues. Le fichier SHA-256 permet de vérifier l’intégrité de l’archive.

`TS1-Cheat-Crystals-*-multi.zip`

## Installation

1. Fermez le jeu et décompressez l’archive.
2. Ouvrez le dossier d’installation de The Sims que vous utilisez, celui qui contient `sims.exe`.
3. Copiez le dossier `TS1CheatCrystals` depuis le dossier `Downloads` de l’archive vers le dossier `Downloads` du jeu. Créez `Downloads` si nécessaire. Le chemin final doit ressembler à `[dossier de sims.exe]\Downloads\TS1CheatCrystals\TS1FundsCrystal.iff.` Évitez de créer un dossier `Downloads\Downloads.`
4. Gardez un seul exemplaire de chaque cristal, y compris en cas de mise à jour. Renommer un fichier conserve l’identifiant de l’objet. Laissez les fichiers `README` en dehors du dossier du jeu et relancez The Sims.

## Désinstallation

Désactivez le gel des besoins avant de retirer le cristal correspondant. Vendez les cristaux placés sur vos terrains, sauvegardez et fermez le jeu. Supprimez ensuite les fichiers IFF voulus ou le dossier `Downloads\TS1CheatCrystals.` Les changements déjà sauvegardés restent dans la partie.

## Compatibilité

Cette version est conçue pour The Sims Legacy Collection avec toutes les extensions. Les fonctions de célébrité utilisent Superstar et les fonctions magiques utilisent Abracadabra. Les menus, descriptions et messages sont disponibles en 17 langues et suivent les paramètres du jeu. L’archive contient une notice `README` dans chacune de ces langues.

Après le chargement d’une partie, réactivez le gel des besoins si vous souhaitez le conserver.
