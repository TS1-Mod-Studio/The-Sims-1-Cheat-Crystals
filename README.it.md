Sette oggetti animati per modificare i fondi della famiglia, i bisogni, le abilità, le relazioni, la carriera, la fama e le risorse magiche. Puoi installare l’intero set o scegliere i singoli cristalli. Ognuno costa §1 e si trova nella modalità Compra, in Varie → Tutto (∞). Colloca il cristallo sul lotto, seleziona un Sim e fai clic sul cristallo per aprire il menu.

## Installazione

1. Chiudi il gioco ed estrai l’archivio.
2. Apri la cartella dell’installazione di The Sims che usi, quella che contiene `sims.exe`.
3. Copia la cartella `TS1CheatCrystals` dalla cartella `Downloads` dell’archivio alla cartella `Downloads` del gioco. Se necessario, crea `Downloads`. Il percorso finale sarà, ad esempio, `[cartella di sims.exe]\Downloads\TS1CheatCrystals\TS1FundsCrystal.iff.` Evita di creare `Downloads\Downloads.`
4. Conserva una sola copia di ogni cristallo anche dopo un aggiornamento. Rinominare un file lascia invariato l’identificativo dell’oggetto. Lascia i file `README` fuori dalla cartella del gioco e riavvia The Sims.

## Disinstallazione

Sblocca i bisogni prima di togliere il cristallo corrispondente. Vendi i cristalli sui lotti in cui li hai collocati, salva la partita e chiudi il gioco. Rimuovi quindi i singoli file IFF oppure l’intera cartella `Downloads\TS1CheatCrystals.` Le modifiche già salvate rimangono nella partita.

## Compatibilità

Questa versione è pensata per The Sims Legacy Collection con tutte le espansioni. Le funzioni legate alla fama usano Superstar e quelle magiche usano Magie e Incantesimi. Menu, descrizioni e messaggi sono disponibili in 17 lingue e seguono la lingua del gioco. L’archivio contiene un file `README` per ciascuna di queste lingue.

Dopo aver caricato una partita, blocca di nuovo i bisogni se vuoi mantenerli fissi.
