**Take control of your Sims' lives without typing cheat codes.**

Cheat Crystals is a collection of seven animated, standalone objects for The Sims 1. Manage your Sims' skills, needs, household funds, relationships, careers, fame and magic directly through in-game menus.

Install the full collection or choose only the crystals you want to use. Each crystal costs just §1.

## The seven crystals

|Crystal|Features|
|-|-|
|📘 **Skills**|Set any of the six skills from level 0 to 10, maximize or reset all skills.|
|📊 **Needs**|Set needs to maximum, minimum or 50%, fill individual needs, deplete energy or freeze needs.|
|💰 **Funds**|Add or subtract Simoleons, add §1,000,000 or reset household funds.|
|💗 **Relationships**|Manage relationships and household ties, add friends or acquaintances and access romance options for eligible adults.|
|💼 **Career**|Choose from 20 careers and set career levels 1–10.|
|⭐ **Fame**|Set fame from 0 to 5 stars in half-star steps, start or end a superstar career.|
|🔮 **Magic**|Add MagiCoins and 31 kinds of magical ingredients, individually or in bundles.|

### Detailed features

<details>

</details>

<details>
<summary><strong>Career Crystal</strong></summary>

* Choose from 20 careers and levels 1–10 for the active adult human Sim, outside work.

* Requires Makin’ Magic.
* File: `TS1MagicCrystal.iff`.

</details>

## Installation

1. Close the game and extract the downloaded ZIP file.
2. Open your game installation folder containing `sims.exe`.
3. Copy the `Downloads` folder from the extracted archive into the game folder. Merge it with the existing `Downloads` folder if necessary.
4. Keep all seven IFF files or remove the crystals you do not want to install. The `README` folder can stay with the extracted archive.
5. Restart the game.

Example installation path:

```text
<folder containing sims.exe>\\Downloads\\TS1CheatCrystals\\TS1FundsCrystal.iff
```

### How to use

1. Open **Buy Mode → Miscellaneous → All (∞)**.
2. Purchase a crystal for §1 and place it on your lot.
3. Select a Sim and click the crystal to open its interaction menu.

### Updating from an older version

Keep only one copy of each crystal. Check older folders named `TS1CrystalVariants`, `TS1RelationshipCrystal`, `TS1CareerCrystal`, `TS1FameCrystal` and `TS1MagicCrystal`. Renaming an IFF file does not change its object ID, so duplicate files may conflict.

## Compatibility and languages

This release was prepared for **The Sims Legacy Collection with all expansions**.

* Fame requires **Superstar**.
* Magic requires **Makin’ Magic**.
* Compatibility with other editions of The Sims 1 is not confirmed for this release.

Object menus, descriptions and dialogs support 17 language versions and follow your game's language setting. The archive includes 17 localized instruction files: Danish, Dutch, English, Finnish, French, German, Italian, Japanese, Korean, Norwegian, Polish, Portuguese (Brazil), Spanish, Swedish, Thai, Simplified Chinese and Traditional Chinese. The English instructions cover both US and UK English.

## Uninstallation

1. Unfreeze needs before removing the Needs Crystal.
2. Sell the crystals on any lots where you placed them.
3. Save the game and close it.
4. Remove the selected IFF files or the entire `Downloads\\TS1CheatCrystals` folder.

Changes already saved in the game will remain.
