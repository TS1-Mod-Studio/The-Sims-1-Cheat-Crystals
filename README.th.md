## ดาวน์โหลด

**[ดาวน์โหลดคริสตัลสูตรโกง – GitHub Releases](../../releases/latest)**

ดาวน์โหลดไฟล์ ZIP จากส่วน Assets ของรุ่นล่าสุด ภายในมีไฟล์ IFF ครบทั้ง 7 ไฟล์และคู่มือ 17 ภาษา สามารถใช้ไฟล์ SHA-256 ตรวจสอบความถูกต้องของไฟล์ ZIP ได้

`TS1-Cheat-Crystals-*-multi.zip`

## การติดตั้ง

1. ปิดเกมและแตกไฟล์ ZIP
2. เปิดโฟลเดอร์ติดตั้งของเกมที่คุณใช้เล่นจริง ซึ่งเป็นโฟลเดอร์ที่มีไฟล์ `sims.exe` โฟลเดอร์นี้อยู่คนละที่กับโฟลเดอร์เอกสารของ Windows
3. คัดลอกโฟลเดอร์ `TS1CheatCrystals` จาก `Downloads` ที่แตกไฟล์แล้วไปไว้ใน `Downloads` ของโฟลเดอร์ติดตั้งเกม หากไม่มี `Downloads` ให้สร้างขึ้นมา ตัวอย่างตำแหน่งที่ถูกต้องคือ `<โฟลเดอร์ที่มี sims.exe>\Downloads\TS1CheatCrystals\TS1FundsCrystal.iff` ระวังอย่าให้เกิดโฟลเดอร์ `Downloads` ซ้อนกัน ไฟล์ IFF แต่ละไฟล์คือคริสตัลหนึ่งชนิด เลือกคัดลอกเฉพาะไฟล์ที่ต้องการได้ โดยเก็บ `README` แยกจากโฟลเดอร์เกม
4. เก็บคริสตัลแต่ละชนิดไว้ในเกมเพียงชุดเดียว ตรวจดูโฟลเดอร์รุ่นก่อน เช่น `TS1CrystalVariants`, `TS1RelationshipCrystal`, `TS1CareerCrystal`, `TS1FameCrystal` และ `TS1MagicCrystal` การเปลี่ยนชื่อไฟล์ไม่ได้แก้ปัญหารหัสวัตถุซ้ำกัน หากใช้งานเวอร์ชันที่มีการดัดแปลงอยู่ ให้ตรวจสอบก่อนว่าต้องการเก็บเวอร์ชันใด
5. เปิดเกมอีกครั้งแล้วหาคริสตัลในโหมดซื้อ

## การถอนการติดตั้ง

หากตรึงความต้องการไว้ ให้ยกเลิกการตรึงก่อน ขายคริสตัลบนพื้นที่ที่ใช้ บันทึกเกมแล้วปิดเกม จากนั้นลบโฟลเดอร์ `Downloads\TS1CheatCrystals` หรือเฉพาะไฟล์ IFF ที่เลือก การลบคริสตัลไม่ย้อนการเปลี่ยนแปลงของเงิน ความสัมพันธ์ ทักษะ หรือรายการอื่นที่บันทึกลงในเกมแล้ว

## ความเข้ากันได้และภาษา

จัดทำสำหรับ The Sims Legacy Collection ที่มีภาคเสริมครบ ยังไม่ได้ตรวจสอบรุ่นเก่า แพลตฟอร์มอื่น หรือเกมที่มีเฉพาะภาคหลัก ฟังก์ชันชื่อเสียงต้องใช้ Superstar และฟังก์ชันเวทมนตร์ต้องใช้ Makin’ Magic เมนู คำอธิบาย และกล่องข้อความรองรับ 17 ภาษา โดยแสดงตามการตั้งค่าของเกม

ชุดนี้ไม่แก้ไข `sims.exe`

## ข้อเสนอแนะและรายงานข้อผิดพลาด

หากพบข้อผิดพลาดหรือมีข้อเสนอแนะ โปรด [เปิด Issue](../../issues) พร้อมระบุเวอร์ชันเกม ภาษา เวอร์ชันม็อด คริสตัลที่เกี่ยวข้อง และขั้นตอนที่ทำให้เกิดปัญหา
